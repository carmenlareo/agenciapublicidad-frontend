

# Agencia Publicidad

Aplicación pensada para pedir un presupuesto por un cliente y administrar en un dashboard los clientes y los presupuestos.

El objetivo principal es ofrecer un espacio para centralizarlo y gestionar los clientes y los presupuestos.

- Ver estado de clientes y presupuestos
- Crear nuevos clientes y presupuestos 
- Buscar clientes y presupuestos de forma fácil y visual.
- Consultar información detallada de presupuestos y clientes.
- Crear y gestionar listas.

## Tecnologías

- **React 19** + **Vite**
- **React Router DOM** — navegación entre páginas
- **Axios** — llamadas a la API
- **CSS Modules** — estilos encapsulados por componente


## Funcionalidades

-Carga de Clientes  y presupuestos
-Envio de presupuestos por whasap
-Crear nuevo cliente
-Crear nuevo presupuesto
-Listado por estado de presupuestos
-Busquedas clientes y presupuestos
-Enviar formulario a un correo (en proceso)
-Admin para acceder a Dashboard (en proceso)
